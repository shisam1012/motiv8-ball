# 🎱 Motiv8-Ball

**Motiv8-Ball** is a modern, inspirational take on the classic Magic 8-Ball toy. Instead of vague predictions, this digital ball provides users with motivational quotes and positive affirmations to boost productivity and mindset.

## ✨ Features
- **Interactive UI:** Smooth "fade in" animations for an engaging user experience.
- **Randomized Quotes:** A diverse pool of motivational messages that rotate with every click.
- **Fully Responsive:** Optimized for a seamless experience across desktops, tablets, and smartphones.
- **Clean Aesthetic:** A minimalist design focused on delivering the message without distractions.
